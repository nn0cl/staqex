## Red evidence

Added `tests/test_liss_0510_lexical_scope_red.py` with four scenarios:
inner State shadow and outer restoration, cross-type inner shadow, same-scope
duplicate rejection, and per-binding State consumption. The current compiler
does not expose scoped binding identity/declaration spans or the required
duplicate diagnostic, so the suite is intended to be Red. One scenario also
captures the current BlockExpr limitation: it permits `let`-based expression
blocks rather than general statement blocks.
